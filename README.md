## ✨ 功能

| 功能 | 说明 |
| --- | --- |
| 🏷 **质量等级** | 综合点赞、投币、收藏三项给出 S/A/B/C，比单看点赞率更可靠 |
| 🧭 **分区自适应** | 按你本地积累的同分区视频比较（知识区和鬼畜区的正常水平差别很大），样本不足时自动使用固定标准 |
| 🧪 **防小样本误判** | 播放量不足（默认 1000）显示「样本少」；比率先向平均值平滑，30 播放 2 赞不会被评成优质 |
| 🆕 **新视频标记** | 发布不足 24 小时的视频标「新」，提醒数据还在变化 |
| 🙈 **淡化 / 隐藏低质视频** | 可选：把 C 级视频淡化或隐藏（不影响新视频和样本少的视频） |
| 🗺 **覆盖场景** | 首页、分区 / 频道页、热门 / 排行榜、搜索结果、视频页右侧推荐、视频详情页标题旁、UP 主空间，可分别开关 |
| ⚡ **省请求** | 卡片滚动到附近才请求；同一视频只请求一次；结果跨页面缓存 2 小时 |
| 🚦 **防风控** | 限制并发与间隔；遇到 B 站限流自动暂停并指数退避；失败自动重试 3 次，之后可手动点「重试」 |
| ⚙ **图形化设置** | 油猴菜单 →「⚙ 视频质量标注设置」，无需改代码 |

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）。
2. 打开下面的链接，在弹出页面点「安装」：

   **https://raw.githubusercontent.com/fhan235/bilibili-video-quality/master/bilibili-video-quality.user.js**

3. 打开 B 站即可生效。脚本带有自动更新地址，新版本发布后油猴会自动更新。

> **从旧版本升级**：v4 已经合并了之前的详情页版、首页版、首页简洁版和全场景版四个脚本。请在油猴管理面板里**删除旧的脚本**，否则会出现重复标注。

## 📊 评级方法

### 1. 三项比率

| 指标 | 公式 | 全站平均水平（参考） | 权重 |
| --- | --- | --- | --- |
| 点赞率 | 点赞 ÷ 播放 | 3.5% | 40% |
| 投币率 | 投币 ÷ 播放 | 0.8% | 35% |
| 收藏率 | 收藏 ÷ 播放 | 1.0% | 25% |

投币要消耗硬币、收藏代表「以后还想看」，比点赞更能反映内容价值，所以三项一起看。

### 2. 小样本平滑

计算前先给每个视频加上 2000 次「平均水平」的播放：

```
平滑后比率 = (实际次数 + 平均比率 × 2000) ÷ (播放量 + 2000)
```

播放量很大时几乎不受影响；播放量很小时会被拉向平均值，避免几十次播放的视频因为偶然的几个赞被评成 S。

### 3. 综合分

```
综合分 = Σ 权重 × log₂(平滑后比率 ÷ 平均比率)
```

0 代表全站平均水平；+1 大约相当于三项都是平均的 2 倍；-1 大约相当于都只有一半。

### 4. 等级

| 等级 | 固定标准（综合分） | 分区自适应（在本地同分区样本中超过） |
| --- | --- | --- |
| **S** | ≥ +0.80 | 90% |
| **A** | ≥ +0.25 | 65% |
| **B** | ≥ -0.35 | 25% |
| **C** | 其余 | 其余 |

**分区自适应**：脚本会把你浏览过的视频（播放 ≥ 1000、发布超过 24 小时）按分区记录综合分，每个分区最多保留最近 300 个。某分区样本满 30 个后，就按该视频在本分区里的排名评级；不满 30 个时自动使用固定标准。

> 注意：样本来自你自己刷到的视频（推荐流本身已经偏向较好的视频），所以分区等级的含义是「在你平时看到的同类视频里排第几」，而不是全站排名。

悬停在标注上可以看到：等级依据、播放 / 点赞 / 投币 / 收藏的数量和比率、分区、发布时间、综合分。

## ⚙ 设置

油猴菜单 →「⚙ 视频质量标注设置」：

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 评级方式 | 分区自适应 | 也可选「固定标准」 |
| 最低播放量 | 1000 | 低于此值显示「样本少」 |
| 新视频时长 | 24 小时 | 新视频标「新」，不参与淡化 / 隐藏 |
| C 级视频 | 正常显示 | 可选「淡化」（悬停恢复）或「隐藏」 |
| 显示位置 | 全部开启 | 六个场景分别开关 |
| 数据缓存 | 2 小时 | 同一视频在此时间内不重复请求 |
| 最大并发数 / 请求间隔 | 3 / 250 ms | 网络不好或经常提示限流时可调小并发、调大间隔 |

菜单里还有「🗑 清除缓存与本地基准」，会清空数据缓存和分区样本。

## 🔧 技术说明

- 数据来源：`https://api.bilibili.com/x/web-interface/view?bvid=…`（精确数字），不读取页面上「1.2万」这类近似值。
- 详情页按网址里的 BV 号请求，并带请求序号，B 站单页切换视频时不会显示上一个视频的数据。
- 卡片按「当前链接里的 BV 号」标注：B 站复用卡片（换一换、无限滚动）时会自动重新标注；骨架屏卡片等渲染完成后再标注。
- 只监听新增节点和链接变化，忽略播放器内部（弹幕）的 DOM 变化。
- 所有界面用 `textContent` 构建，不拼接 HTML；设置面板放在 Shadow DOM 中，不受 B 站样式影响。
- 只访问 `api.bilibili.com`（`@connect`），不收集、不上传任何数据。

## ❓ 常见问题

**看不到标注？**
确认油猴和脚本已启用、旧版脚本已删除；在设置里检查对应场景是否开启。B 站改版可能导致卡片结构变化，欢迎提 Issue 并附上页面地址。

**一直显示「⚠ 重试」？**
多半是触发了 B 站风控。脚本会自动暂停退避；仍频繁出现时，可在设置中把并发调到 1–2、间隔调到 500 ms 以上。

**会被封号吗？**
脚本只读取公开的视频统计数据，请求频率受控且有缓存，与正常浏览相当。
