# Bilibili 视频质量标注脚本

Tampermonkey（油猴）用户脚本集，在 B 站自动根据播放量、点赞数、投币数的比值标注视频质量。

## 📦 包含两个脚本

| 脚本 | 使用场景 | 说明 |
|------|---------|------|
| `bilibili-video-quality.user.js` | 视频详情页 | 点进视频后，在标题旁显示质量标签 |
| `bilibili-video-quality-homepage.user.js` | **首页/推荐页** | **无需点进视频**，直接在每个视频卡片封面上显示质量标签 |

> 💡 两个脚本可以同时安装，互不冲突。

## 📸 效果预览

- **首页版**：视频卡片封面左上角显示 **🔥 优质** 或 **📊 普通** 标签
- **详情页版**：视频标题旁显示 **🔥 优质视频** 或 **📊 普通视频** 标签
- 鼠标悬浮任一标签都可查看详细数据分析面板

## 📐 判断规则

一个视频被标记为「优质视频」需满足以下**任一**条件：

| 条件 | 公式 | 说明 |
|------|------|------|
| 点赞率达标 | 点赞数 / 播放量 ≥ **5%** | 每 100 次播放有 5 个以上点赞 |
| 投币率达标 | 投币数 / 播放量 ≥ **点赞率 / 2** | 投币率超过点赞率的一半 |

> 举例：一个视频 10 万播放、6000 点赞、2500 投币
> - 点赞率 = 6000 / 100000 = 6% ≥ 5% ✅ → 好视频
> - 投币率 = 2500 / 100000 = 2.5%, 阈值 = 6% / 2 = 3% → 2.5% < 3% ❌
> - 最终：满足条件 1，标记为 🔥 优质视频

## 🚀 安装方法

### 1. 安装浏览器扩展

安装以下任一用户脚本管理器：

- [Tampermonkey](https://www.tampermonkey.net/)（推荐）
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)（仅 Firefox）

### 2. 安装脚本

**方法一：本地安装**

1. 打开 Tampermonkey → 管理面板 → 新建脚本
2. 将 `.user.js` 文件的全部内容粘贴进去
3. 按 `Ctrl+S` 保存
4. 推荐安装 **首页版**（`bilibili-video-quality-homepage.user.js`），两个脚本也可同时安装

**方法二：文件拖拽**

1. 直接将 `.user.js` 文件拖到浏览器窗口中
2. Tampermonkey 会自动识别并弹出安装确认

### 3. 使用

- **首页版**：打开 bilibili.com 首页，每个视频卡片封面左上角会自动显示质量标签，滚动加载新视频时也会自动标注
- **详情页版**：点进任意视频，标题旁会显示质量标签

## ⚙️ 自定义配置

在脚本顶部的 `CONFIG` 对象中可以调整参数：

```javascript
const CONFIG = {
    LIKE_RATIO_THRESHOLD: 0.05,  // 点赞率阈值，默认 5%
    COIN_RATIO_FACTOR: 0.5,      // 投币率 = 点赞率 × 此系数
    DEBUG: false,                 // 开启后在控制台输出调试信息
};
```

## 🔧 技术细节

### 详情页版
- **DOM 轮询**：使用轮询等待页面数据加载完成（B 站 SPA 异步加载）
- **路由监听**：MutationObserver 监听 URL 变化，视频切换时自动重新评估
- **数字解析**：支持解析 "万" "亿" 等中文数字单位

### 首页版
- **B 站 API**：通过 `api.bilibili.com/x/web-interface/view` 接口获取视频的精确数据
- **并发控制**：使用任务队列控制并发请求数（默认 3 个），避免触发 B 站限流
- **请求延迟**：每个请求间隔 200ms，确保不对服务器造成压力
- **数据缓存**：缓存已请求的视频数据（默认 10 分钟），减少重复请求
- **DOM 监听**：MutationObserver 监听页面变化，无限滚动加载新卡片时自动标注
- **Hover 详情**：鼠标悬浮标签可查看完整数据分析面板
